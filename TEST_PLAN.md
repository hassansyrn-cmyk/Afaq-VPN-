# Test Plan
Test on Android 7/API 24 and the newest supported Android: grant and deny VPN consent; connect/disconnect; invalid key, address and endpoint; unreachable server; Wi-Fi loss; Wi-Fi/mobile handover; background and force-close behavior; notification persistence and Stop action; reboot behavior; auto-connect preference; DNS leak using two independent test sites; IPv6 leak on a network with native IPv6; before/after public IP; traffic counters; grep release and debug Logcat for keys/config; RTL/LTR, light/dark, portrait/landscape and small screens. A passing UI build is not proof of tunnel, DNS, or IPv6 protection.
